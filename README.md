Conversor — English
How to open
No installation required for the person using it. Double-click Conversor.exe — it opens in its own window (no browser needed).

If the window opens blank, you're missing the Microsoft Edge WebView2 Runtime (the engine pywebview uses on Windows). Install the "Evergreen" runtime from developer.microsoft.com/microsoft-edge/webview2 and open it again. It's preinstalled on virtually all up-to-date Windows 10/11 machines, so this is rare.

Building the .exe yourself instead of just running it? See BUILD.md.

What you can do
Two tabs
📄 Arquivos — documents and data files (TXT, PDF, DOCX, HTML, RTF, CSV, JSON, XML, XLSX, YAML)
🖼️ Imagens — images (PNG, JPG, WEBP, BMP, GIF)
Converting a file
Selecionar entrada — click, pick a file. The app reads its extension and shows its name and size
Saída — a button appears for every format that file can become. Click one and the conversion runs immediately — no separate "convert" button
Wrong tab? If you pick a file that belongs to the other tab, a small suggestion appears to switch tabs for you
Image-only actions
Comprimir — opens a quality slider (1–100), then a button to run it
Redimensionar — opens width/height fields and a "keep aspect ratio" checkbox, then a button to run it
After a conversion
Abrir arquivo — opens the converted file in your default program for that format
Abrir pasta — opens the folder it was saved in
Nova conversão — clears the current file so you can start over
Reference list
Ver todas as conversões disponíveis, below the tabs — expands a full list of every supported conversion. It's generated from the app's own conversion map, so it can't go out of date on its own
Supported conversions
Documents & data: TXT↔PDF, TXT↔DOCX, PDF→TXT, PDF→DOCX, DOCX↔TXT, DOCX↔PDF, HTML→PDF, HTML→TXT, RTF→TXT, CSV↔JSON, CSV↔XML, CSV↔XLSX, JSON↔XML, JSON↔XLSX, JSON↔YAML, XML↔YAML, XLSX↔JSON

Images: convert between PNG/JPG/JPEG/WEBP/BMP/GIF, compress (adjustable quality), resize (with or without keeping proportions)

Where do converted files go?
Next to the original file, same folder — never overwritten. The new file gets a suffix:

_converted for format conversions
_compressed for image compression
_resized for image resizing
PDF and DOCX conversions are text/paragraph-based — they don't preserve complex layout, columns, or tables from the original.

Conversor
Como abrir
Não precisa instalar nada. Dê duplo clique em Conversor.exe — abre numa janela própria (sem precisar de navegador).

Se a janela abrir em branco, falta o Microsoft Edge WebView2 Runtime (o motor que o pywebview usa no Windows). Baixe o runtime "Evergreen" em developer.microsoft.com/microsoft-edge/webview2 e abra de novo. Isso é raro — já vem instalado na grande maioria dos Windows 10/11 atualizados.

Vai gerar o .exe você mesmo em vez de só usar? Veja o BUILD.md.

O que dá pra fazer
Duas abas
📄 Arquivos — documentos e dados (TXT, PDF, DOCX, HTML, RTF, CSV, JSON, XML, XLSX, YAML)
🖼️ Imagens — imagens (PNG, JPG, WEBP, BMP, GIF)
Convertendo um arquivo
Selecionar entrada — clique, escolha o arquivo. O app lê a extensão e mostra nome e tamanho
Saída — aparece um botão pra cada formato que aquele arquivo pode virar. Clique num e a conversão já roda na hora — não tem botão "converter" separado
Aba errada? Se você escolher um arquivo que pertence à outra aba, aparece uma sugestão pra trocar de aba automaticamente
Ações exclusivas de imagem
Comprimir — abre um controle de qualidade (1–100), depois um botão pra executar
Redimensionar — abre campos de largura/altura e uma caixa "manter proporção", depois um botão pra executar
Depois de converter
Abrir arquivo — abre o arquivo convertido no programa padrão daquele formato
Abrir pasta — abre a pasta onde foi salvo
Nova conversão — limpa o arquivo atual pra você recomeçar
Lista de referência
Ver todas as conversões disponíveis, abaixo das abas — expande a lista completa de tudo que o app converte. Ela é gerada a partir do próprio mapa de conversões do app, então não tem como ficar desatualizada sozinha
Conversões suportadas
Documentos e dados: TXT↔PDF, TXT↔DOCX, PDF→TXT, PDF→DOCX, DOCX↔TXT, DOCX↔PDF, HTML→PDF, HTML→TXT, RTF→TXT, CSV↔JSON, CSV↔XML, CSV↔XLSX, JSON↔XML, JSON↔XLSX, JSON↔YAML, XML↔YAML, XLSX↔JSON

Imagens: converter entre PNG/JPG/JPEG/WEBP/BMP/GIF, comprimir (qualidade ajustável), redimensionar (com ou sem manter proporção)

Pra onde vão os arquivos convertidos?
Pra mesma pasta do arquivo original — nunca sobrescreve nada. O novo arquivo ganha um sufixo:

_converted pra conversões de formato
_compressed pra compressão de imagem
_resized pra redimensionamento de imagem
Conversões de PDF e DOCX são baseadas em texto/parágrafo — não preservam layout complexo, colunas ou tabelas do original.
